================================================================================
PRACTICAL 13: PHP JSON API and Asynchronous CRUD
================================================================================

OVERVIEW:
This practical focuses on creating backend PHP REST-like API endpoints that return
JSON data and consuming them asynchronously from the frontend using the JavaScript Fetch API.

KEY FEATURES & OBJECTIVES:
1. PHP scripts configured to return structured JSON responses using json_encode().
2. Performing CRUD actions asynchronously without refreshing or reloading the webpage.
3. Handling GET and POST HTTP requests properly.
4. Managing UI states for loading spinners, success messages, and error alerts.

TECHNOLOGIES USED:
- PHP (JSON headers & output)
- JavaScript (Fetch API / Async-Await)
- HTML5 / CSS3
